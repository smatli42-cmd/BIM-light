# BIM-light

Vlastní lehký BIM program pro architekty (web, později desktop). Teď etapa 0: pískoviště se stěnami, kótami a zobrazením.

- Vyzkoušet: https://smatli42-cmd.github.io/BIM-light/
- Spuštění lokálně: `npm install`, pak `npm run dev`
- Testy: `npm run test` a `npm run test:e2e`
- Rozhodnutí a pravidla: složka `docs/`, stav práce: `docs/STAV.md`, pravidla pro Claude Code: `CLAUDE.md`
